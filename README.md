# team-Bionic_Pilot

这个项目灵心巧手o6和机械臂rm75-6f的他们之间使用RS485进行通信协议

See [CONTRIBUTING.md](CONTRIBUTING.md) for branch and code review rules.

## SDK directories

- `linkerhand-cpp-sdk`: LinkerHand C++ SDK with O6 support, tracked directly in this repository.
- `RM_API2`: RealMan API2 SDK with C/C++ support for RM75-6F, tracked directly in this repository without the top-level `Python` SDK directory.

After cloning this repository, no submodule initialization is required.
