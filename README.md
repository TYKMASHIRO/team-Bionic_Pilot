Initial repository setup.

## SDK submodules

- `linkerhand-cpp-sdk`: LinkerHand C++ SDK with O6 support.
- `RM_API2`: RealMan API2 SDK with C/C++ support for RM75-6F.

After cloning this repository, initialize the SDK directories with:

```bash
git submodule update --init --recursive
```
